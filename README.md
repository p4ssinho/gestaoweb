# 🌱 Mais Gestão — Plataforma Web

## Sobre o projeto

A plataforma Mais Gestão é uma solução web desenvolvida para apoiar as atividades do projeto Mais Gestão, voltado ao fortalecimento da agricultura familiar.

O sistema busca facilitar a divulgação de informações, ampliar a visibilidade das ações do projeto e centralizar conteúdos relevantes para agricultores familiares, equipes técnicas e demais interessados.

A plataforma também dispõe de um ambiente administrativo destinado ao gerenciamento e à atualização dos conteúdos disponibilizados ao público.

## 🎯 Objetivos

- Fortalecer a visibilidade da agricultura familiar.
- Facilitar o acesso às informações e ações do projeto.
- Centralizar a divulgação de notícias e conteúdos institucionais.
- Simplificar o gerenciamento de informações pela equipe responsável.
- Promover a utilização de ferramentas digitais no contexto da agricultura familiar.
